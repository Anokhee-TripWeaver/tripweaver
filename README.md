# 🌍 TripWeaver – AI-Powered Travel Planning Platform

## 🚀 Live Demo

🔗 Application:https://tripweaver-frontend.vercel.app/

## Overview

TripWeaver is a full-stack AI-powered travel planning and booking platform designed to simplify trip planning through intelligent recommendations, automated itinerary generation, and seamless booking experiences. The application combines Generative AI, real-time travel services, and social travel features to help users plan personalized trips efficiently.

### Key Features

- 🤖 AI-Powered Itinerary Generation using Google Gemini AI
- 💬 Intelligent Travel Chatbot powered by Groq
- 🔍 Destination Discovery and Recommendations
- 📍 Google Maps & Places Integration
- ✈️ Flight Search with Amadeus API
- 💳 Secure Payments using Stripe
- 📧 Email Notifications
- 👥 Open Trip Social Travel Feature
- 🎯 Personalized Travel Recommendations
- 💰 Budget-Based Travel Planning
- 📜 Trip History Management

## Tech Stack

**Frontend:** React.js, JavaScript, HTML5, CSS3

**Backend:** Spring Boot, Java, Spring Security

**Database:** MySQL

**APIs & Services:** Google Gemini AI, Groq API, Google Maps API, Google Places API, Amadeus API, Stripe API, JavaMail API

**Authentication:** Google OAuth 2.0

## Project Highlights

- Developed a scalable full-stack travel planning platform using React and Spring Boot.
- Integrated Generative AI to create personalized travel itineraries.
- Built an AI-powered chatbot capable of assisting users with trip planning and booking.
- Implemented secure authentication using Google OAuth 2.0.
- Enabled real-time location discovery through Google Maps and Places APIs.
- Integrated Stripe for secure payment processing and booking management.
- Added social travel functionality allowing users to connect through Open Trip.
